# Car_light_RnD — сайт мастерской автосвета

Концепт-редизайн сайта мастерской по полировке и ремонту фар в Ростове-на-Дону. Контакты, график и цены взяты из карточки на Яндекс Картах, фотографии настоящие, отзывы без изменений.

**Демо:** https://vadex-web.github.io/car-light-rnd/

## Что внутри

- Первый экран: услуга, цена полировки и две кнопки
- «До и после» на реальном фото мастерской
- Описание полировки: когда нужна и когда её недостаточно
- Прайс из каталога с кнопкой записи у каждой услуги
- Галерея работ с просмотром крупным планом
- Отзывы с Яндекс Карт (6 из 6)
- Запись: звонок, WhatsApp или Telegram с готовым текстом заявки
- Контакты, часы работы, карта Яндекса
- Мобильное меню и нижняя панель «Позвонить / Записаться»
- Разметка schema.org (AutoRepair), Open Graph, семантические теги

## Стек

HTML, CSS, JavaScript без сборки и зависимостей.

| Файл | Назначение |
|---|---|
| `index.html` | страница и разметка |
| `style.css` | стили |
| `script.js` | меню, статус «открыто», форма заявки, просмотр фото |

## Запуск

Откройте `index.html` в браузере или включите GitHub Pages для ветки `main`.
